# Omarchy IME（Omarchy 拼音）安装故障排查与使用指南

项目地址：<https://github.com/Freecode100Year/omarchy-ime>（镜像：<https://gitlab.com/sj9292008133/omarchy-ime>）

## 一、项目简介

Omarchy IME 是给 Omarchy / Hyprland（Wayland）和 Fcitx5 用的离线中文输入法：

- 输入引擎用 Rust 写成，完全在本机运行，不联网；
- 候选框的颜色和字体跟着 Omarchy 主题自动变化；
- 自带离线拼音词库（雾凇拼音，GPL-3.0），可选五笔拼音混输，会记住你常用的词。

## 二、安装

用普通用户运行（不要加 `sudo`，也不要先 `sudo -i` 切到 root）：

```bash
curl -fsSL https://raw.githubusercontent.com/Freecode100Year/omarchy-ime/main/install.sh | bash
```

安装程序会在需要时自己调用 `sudo pacman`。装完后会自动启用输入法，按 `Super + I` 切换。

## 三、安装出错怎么办

### 1. 编译器崩溃或被杀掉（内存不够）

现象：编译到一半出现 `internal compiler error`、`Please include the complete backtrace`、`signal: 9, SIGKILL`，或者 `在 build() 中发生一个错误`。

原因：编译需要不少内存。早期版本还要现场编译一个 9 MB 的 SQLite 源文件，并且在 `/tmp` 里编译——Omarchy 的 `/tmp` 直接占用内存。在 Try Omarchy 这类小内存虚拟机里，编译器会因内存耗尽被系统杀掉。

已在提交 `d03f810` 修复：

- 改用系统自带的 SQLite（`sqlite` 软件包），不再现场编译它；
- 在硬盘上的 `~/.cache` 里编译，不占内存；
- 按可用内存决定同时编译几个任务（大约每 1.5 GB 一个，最少 1 个）。

还遇到时：关掉浏览器等占内存的程序，重新运行安装命令。小内存机器会一个一个慢慢编译，可能要 10 分钟以上，看起来像卡住时请耐心等待。

### 2. 用 root 运行

现象：`正在尝试以 root 用户运行 makepkg，这是不被允许的`，或者安装程序提示用普通用户运行。

原因：Arch 的打包工具 `makepkg` 不允许用 root 运行，安装程序也会拒绝 root。

解决：退出 root（输入 `exit`），用平时登录的普通用户重新运行安装命令。

### 3. 提示版本降级（downgrade）

现象：安装时 pacman 提示要把 `omarchy-ime-git` 降级到更低的版本号。

原因：版本号里的 `r数字` 是 git 提交的数量。如果自己用 `git clone --depth 1` 浅克隆了源码再安装，只能数到 1 个提交，版本号就会比之前装过的低。

解决：直接用上面的一行安装命令（它会完整克隆）；自己克隆时不要加 `--depth 1`。

### 4. 装好了，但输入法列表里找不到、切换不过去

早期版本（提交 `7fd02bb` 之前）的动态库缺少 SONAME，安装完删除编译目录后 Fcitx5 就加载不到它。新版已修复。

如果仍然找不到，运行：

```bash
omarchy-ime-enable --status   # 查看 Fcitx5 是否加载了引擎、是否在输入法列表里
omarchy-ime-enable            # 重新加载并加入输入法列表
```

注意：Omarchy 自带的「输入法」选择菜单只列出它自己的几种输入法，看不到第三方输入法，这是正常的；用 `omarchy-ime-enable` 加入即可。

## 四、日常使用

### 切换输入法

按 `Super + I` 在英文键盘和「Omarchy 拼音」之间切换。

Omarchy 把 `Ctrl + Space` 留给终端使用，所以不要用它切换输入法。

### 常用命令

| 想做什么 | 命令 | 说明 |
| --- | --- | --- |
| 查看状态 | `omarchy-ime-enable --status` | Fcitx5 是否加载了引擎、是否在输入法列表里 |
| 重新启用 | `omarchy-ime-enable` | 重启桌面后输入法不见了时用 |
| 加上五笔拼音混输 | `omarchy-ime-enable --wubi` | 把「Omarchy 五笔拼音混输」加入输入法列表 |
| 试打一个词 | `omarchy-ime --demo nihao` | 在终端里显示候选词，检查词库是否正常 |
| 检查词库 | `omarchy-ime --check` | 检查当前用的词库能否正常读取 |
| 教它一个词 | `omarchy-ime --learn <拼音> <汉字>` | 例如 `omarchy-ime --learn omaqi 欧马奇` |
| 手动同步主题颜色 | `omarchy-ime-theme-sync` | 切换主题时会自动执行，一般不用手动 |

## 五、设置和数据放在哪里

| 文件 | 位置 | 用途 |
| --- | --- | --- |
| 设置 | `~/.config/omarchy-ime/config.toml` | 每页候选数（`page_size`）、模糊音（`fuzzy_typing`）、双拼方案（`double_pinyin`）、五笔版本（`wubi_version`）等 |
| 快捷短语 | `~/.config/omarchy-ime/macros.toml` | 例如输入 `;;date` 得到今天的日期 |
| 学到的词 | `~/.local/share/omarchy-ime/user.sqlite3` | 你常用的词和 `--learn` 教的词，只存在本机 |
| 主题同步钩子 | `~/.config/omarchy/hooks/theme-set.d/50-omarchy-ime-theme` | 切换 Omarchy 主题时自动更新候选框颜色 |

关于自定义词库（要小心）：

- 如果存在 `~/.local/share/omarchy-ime/pinyin.tsv`，它会整个替换系统词库（`/usr/share/omarchy-ime/pinyin.tsv`），不是在原来的基础上补充。只放几个词的话，其他词都会打不出来。
- 五笔词库 `~/.local/share/omarchy-ime/wubi.tsv` 也是一样，会整个替换系统的五笔词库。
- 想加几个词，用 `omarchy-ime --learn`。
- 确实要用自己的整套词库时，先复制系统词库，再在副本上修改：

```bash
cp /usr/share/omarchy-ime/pinyin.tsv ~/.local/share/omarchy-ime/pinyin.tsv
```

改完后重启 Fcitx5，新词库才会生效：

```bash
systemctl --user restart omarchy-fcitx5.service
```

## 六、卸载

用一行命令安装时，源码在装完后就删掉了，可以这样卸载：

```bash
omarchy-ime-theme-sync --restore   # 恢复原来的候选框主题
sudo pacman -R omarchy-ime-git
rm -f ~/.config/omarchy/hooks/theme-set.d/50-omarchy-ime-theme
```

如果手上有源码目录，直接运行里面的 `./uninstall.sh` 也一样。两种方法都会保留你的设置和学到的词（在 `~/.local/share/omarchy-ime`）。
